Uyos YouTube publishing

Uyos publishes AuraDeepDive and is developing Aura the Time Traveler using a private publishing tool that runs on Uyos's own computer. It is used only by Uyos, for its own channels, and is not offered to the public.

Our channels

AuraDeepDive — Follow the evidence. See the bigger picture.

Aura the Time Traveler — The past. The possibilities. A new channel, with its first stories being prepared.

What the tool does with YouTube

With the channel owner's permission, given once through Google's sign-in, the tool:

  • uploads videos that Uyos made to the selected Uyos channel, as private or scheduled until a person approves them;
  • sets each video's title, description, thumbnail and playlists;
  • reads the channel's own analytics and comments, so Uyos can see what's working and reply.

It acts only on Uyos’s connected channels, using separate channel authorizations. It does not access anyone else's YouTube account, and it never makes a video public without a person's approval.

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. How the tool handles the data it receives is in our privacy policy.
